# MathFlow 接口契约（教师端 / 学生端共用）

本文件是前后端之间的**冻结契约**。改接口必须先改这里，并同步 `scripts/test-workflow.mjs`。

约定：

- 所有接口都在 `/api/*`，返回 JSON，`Cache-Control: no-store`。
- 身份由平台注入的请求头决定，前端**无法**伪造；角色存在服务端 `users` 表。
- 未登录 → `401`；角色不符 → `403`；参数错误 → `400`；资源不存在 → `404`。
- 写操作要求同源（`Origin` 必须匹配）。
- 错误响应统一为 `{ "error": "中文提示" }`，界面直接把 `error` 显示给用户即可。
- **本地开发多身份切换**：访问 `/signin-with-chatgpt?as=teacher&return_to=/` 即以教师登录；
  `as=student_a` / `as=student_b` / `as=student_c` 分别是三名学生。
  （仅本地生效；线上由平台真实登录。）

## 页面结构

| 路由 | 页面 | 角色 |
| --- | --- | --- |
| `/` | 按角色重定向 | 任意 |
| `/welcome` | 未登录说明页 | 匿名 |
| `/teacher` | 教师工作台（我的课程） | 教师 |
| `/teacher/course?id=<courseId>` | 课程管理：作业列表 + 提交列表 + 审核 | 教师 |
| `/teacher/stats?id=<courseId>` | 成绩统计与 CSV 导出 | 教师 |
| `/student` | 学生首页：我的课程 + 加入课程 | 学生 |
| `/student/course?id=<courseId>` | 我的作业列表、提交、查看批改结果 | 学生 |

## 类型

类型定义在 `app/domain.ts`，**直接 import，不要自己复制**：

```ts
import type { Assignment, Category, Course, Grade, Submission, User } from '@/app/domain';
import { classify, effectiveScore, isReleased } from '@/app/domain';
```

- `Category` = `'全对' | '部分正确' | '全错'`
- `Submission.status` = `'pending'`（待批改）`| 'graded'`（已批改待审核）`| 'approved'`（教师已定稿）
- `Submission.aiScore`：批改建议分；`finalScore`：教师定稿分。
  界面请用 `effectiveScore(submission)` 取「当前应显示的分」，用 `isReleased()` 判断是否已定稿。

### 批改结果 `Grade`（存在 `submission.aiPayload`）

```ts
type Grade = {
  score: number; maxScore: number; category: Category;
  confidence: number; summary: string;
  questions: {                       // 逐题
    number: number; score: number; maxScore: number;
    verdict: 'correct' | 'partial' | 'wrong';
    summary: string;
    lines: {                         // 逐行错误定位 —— 需求核心
      line: number;                  // 第几行（从 1 开始）
      text: string | null;           // 学生该行原文，识别不到时为 null
      isFirstError: boolean;         // 是否首次出错（同源错误只标第一处）
      issue: string | null;          // 问题描述
      deduction: number;             // 扣分
    }[];
  }[];
  practice: { prompt: string; hints: string[]; expected: string[]; explain: string } | null;
  extensions: { prompt: string; level: '巩固'|'提高'|'拓展'; goal: string }[];
  placeholder: boolean;              // true = 占位批改，不是真实模型结论
  source: string;                    // 'openai:<configured-model>'
  generatedAt: string;
};
```

> **当前版本**：配置服务端 OpenAI 密钥与模型后返回真实图片批改，`placeholder=false`。
> 未配置、超时或模型输出校验失败时，提交保留为 `pending`，`aiScore` 与 `aiPayload` 为 `null`。
> 新版本不再生成占位分数；保留 `placeholder` 字段仅兼容旧载荷。
> `LineAssessment` 增加 `page` 和 `box`：页码与行号从1开始，box为原图归一化 `[x,y,width,height]`，无法定位时为null。

## 接口清单

### `GET /api/me`

当前身份 + 我的课程。

```json
{ "user": { "id": "...", "role": "teacher", "displayName": "..." },
  "courses": [ { "id": "...", "name": "...", "code": "...", "joinCode": "A7K2QM", "term": "..." } ] }
```

### `GET /api/course?id=<courseId>`

课程详情，**按角色返回不同字段**。

教师（必须是该课授课教师）：

```json
{ "course": {...}, "role": "teacher",
  "assignments": [...], "submissions": [...], "students": [ { "studentId": "...", "displayName": "...", "studentNumber": "..." } ] }
```

学生（必须已选课）：`submissions` 只含自己的。

```json
{ "course": {...}, "role": "student", "assignments": [...], "submissions": [...] }
```

### `POST /api/course`

```jsonc
// 教师
{ "op": "create", "name": "数学分析 I", "code": "MATH 101", "term": "2026 秋" }  // → { course }
{ "op": "update", "courseId": "...", "name": "...", "code": "...", "term": "..." } // → { course }
{ "op": "delete", "courseId": "..." }                                            // → { ok: true }

// 学生
{ "op": "join", "joinCode": "A7K2QM", "studentNumber": "2026010101" }            // → { course, enrollment }
```

`create` 成功后返回的 `course.joinCode` 就是给学生用的课程码。

### `GET /api/assignments?courseId=<courseId>`

```json
{ "assignments": [ { "id": "...", "title": "...", "due": "2026-10-01T23:59", "maxScore": 100, "weight": 1, "questions": "...", "rubric": "..." } ] }
```

### `POST /api/assignments`

```jsonc
{ "op": "create", "courseId": "...", "title": "...", "chapter": "第二章",
  "due": "2026-10-01T23:59",   // 必须是 YYYY-MM-DDTHH:mm
  "maxScore": 100, "weight": 1, "questions": "...", "rubric": "..." }  // → { assignment }
{ "op": "delete", "assignmentId": "..." }                              // → { ok: true }
```

### `POST /api/submission`（学生提交）

```jsonc
{ "action": "submit", "assignmentId": "...", "files": ["<uuid>", ...] }  // 1–5 张
// → { submission, placeholder: false, warning?: string }
```

同一学生同一作业重复提交会覆盖原记录并重新批改。

### 重新批改与订正问答

`POST /api/submission`：`{ "action": "regrade", "submissionId": "..." }`。本人或授课教师可调用，已定稿记录拒绝重批；后返回的模型结果不能覆盖更新的照片或教师定稿。

`GET /api/tutor?submissionId=...`：本人或授课教师读取订正记录。

`POST /api/tutor`：`{ "submissionId": "...", "answer": "..." }`。只有本人学生可提交，最多4000字，需已有真实批改结果；返回 `{ feedback: { understood, feedback, nextStep } }`，记录持久保存，不修改成绩。

### `GET /api/submission?id=<submissionId>`（读单份）

本人或该课授课教师可读，其他人 `403`。→ `{ submission, assignment }`

### `POST /api/submission`（教师审核）

```jsonc
{ "action": "review", "submissionId": "...", "score": 88, "feedback": "..." }
// → { submission }   // status 变为 approved，category 按 classify 自动归档
```

分数必须 `0 ≤ score ≤ maxScore`，反馈不能为空，否则 `400`。

### `GET /api/stats?courseId=<courseId>`

```json
{ "course": {...}, "assignments": [...],
  "totals": [ { "studentId": "...", "displayName": "...", "studentNumber": "...",
                "entries": [ { "assignment": {...}, "submission": {...}|null, "countedScore": 88|null, "approved": true } ],
                "approvedCount": 1, "submittedCount": 1, "average": 88, "complete": true } ] }
```

`average` 是**先按满分归一化成百分制、再按 weight 加权**的结果；
未提交与未审核都不计零；`complete=false` 时界面要标注「暂定」。

### `POST /api/stats`（导出 CSV）

请求体 `{ "courseId": "..." }`，返回 `text/csv` 附件。用 `fetch` + `blob` 下载即可。

### 图片

- 上传：`POST /api/files`，`multipart/form-data`，字段名 `file`。
  限制：JPG/PNG/WebP、单张 ≤ 8 MB、最多 5 张（前端也要先校验，给出即时提示）。
  → `{ id }`，把 id 交给 `POST /api/submission`。
- 读取自己上传的：`GET /api/files?id=<uuid>`
- **教师读学生的图**：`GET /api/files?id=<uuid>&owner=<studentId>`
  必须是该提交所属课程的授课教师，否则 `403`。

## 界面要求（两端共同）

1. 加载态、空状态、错误态都要有；错误直接显示接口返回的 `error`。
2. 提交类操作按钮在请求期间禁用，避免重复点击。
3. 移动端可用（学生端主要在手机上拍照上传，优先适配窄屏）。
4. 不要在前端做权限判断后就当作安全边界——服务端才是权威，前端只做体验优化。
